# SupportDesk submission evidence

This folder is reserved for the final presentation artifacts required by the
capstone rubric. The actual video and slide deck must be supplied by the
student because they need to show the student's own account, AWS environment,
and live walkthrough.

Required final files:

- `supportdesk-presentation.mp4` — mandatory presentation video.
- `supportdesk-slides.pptx` or `supportdesk-slides.pdf` — minimum eight slides.

Before recording, collect the screenshots and URLs listed in the root
`README.md` evidence checklist. Use redacted screenshots and public URLs only.
Never record, upload, or commit credentials, tokens, private kubeconfigs, AWS
access keys, or other secrets.
